Intendencia de Aulas

MVP para digitalizar la solicitud de programación por ciclo, conservar versiones inmutables y trazabilidad. El solicitante registra la programación; la asignación administrativa de aula está diferida en la fase actual (ADR-009).

8 tablas PostgreSQL
3 roles operativos
Versionado inmutable
Importación Excel con preview
Ver instrucciones técnicas

Problema

La programación se recibe en múltiples Excel, se consolida manualmente y se pierde trazabilidad.

  • Archivos dispersos por facultad/ciclo.
  • Sin historial confiable de cambios.
  • Se mezcla requerimiento de unidad con decisión de Intendencia.
  • Difícil auditar quién cambió qué y cuándo.

Objetivo del MVP

Centralizar solicitudes por unidad y ciclo, con flujo claro y datos estructurados.

  • Login simulado Google + autorización local.
  • Solicitud por unidad/ciclo con múltiples filas.
  • Versiones completas e inmutables.
  • Asignación de aulas solo por Intendencia.
  • Exportación Excel/CSV y métricas.

Flujo de demostración

Guion E2E del MVP.

Ingreso

Cuenta simulada; se valida rol, autorización y unidad.

Programación

La unidad captura filas o importa Excel con vista previa.

Versión

Se guarda una fotografía completa con autor y fecha.

Fase posterior

La asignación administrativa de aulas queda diferida. El modelo conserva el campo de aula para activarla en una fase futura.

Trazabilidad

Cada guardado crea una nueva versión; el historial se conserva.

Garantías de diseño

Reglas no negociables.

  • El solicitante no asigna aulas; la asignación administrativa está diferida.
  • Versiones inmutables: corregir = nueva versión; v1 es programación de inicio.
  • Validación en servidor y transacciones.
  • Aislamiento por unidad académica para rol SOLICITANTE.
  • Sin borrado físico de históricos.

Pendientes de validación

Decisiones del documento PD-01..PD-14.

  • PD-01 Unidad: facultad/programa/jerarquía.
  • PD-03 Estados y transiciones definitivas.
  • PD-04 Edición tras cierre/asignación.
  • PD-08 Reglas de asignación y desempate.
  • PD-11 Integración SIPUC.
