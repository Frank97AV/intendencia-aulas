# F-06 · Dashboard y presentación

## Objetivo
Entregar visibilidad operativa y una presentación temporal para stakeholders.

## Criterios de aceptación
- CA-06.1: Dashboard muestra totales por estado y avance por unidad. La cobertura de asignación queda diferida junto con F-05 (ADR-009).
- CA-06.2: Página `/presentacion` explica problema, alcance, flujo, modelo, garantías y pendientes.
- CA-06.3: Contenido de presentación aislado en `src/demo/presentacion.ts`.
- CA-06.4: Documentación de gestión y manuales disponible en `docs/`.
- CA-06.5: Existe guion de demo reproducible.
